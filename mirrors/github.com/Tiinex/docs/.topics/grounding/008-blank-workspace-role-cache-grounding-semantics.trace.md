# Blank-Workspace Role-Cache Grounding Semantics

## Objective

Define the smallest existing Tiinex semantic contract that lets a fresh Role ground correctly when the selected Workspace is intentionally blank/minimal and exact route-bounded authority is supplied through qualified cache and Role material rather than a complete repository snapshot.

The result must close the remaining process-discoverability question for this material shape without turning package/cache presence into authority and without introducing a new schema family unless existing Role/Task/Handoff/Decision/Relation semantics are demonstrably insufficient.

## Required Questions

- What may a qualified Workspace dependency/Role cache establish: availability/provenance only, or any stronger semantic claim?
- How must a controlling Task/Handoff/Role make an applicable or required process forward discoverable when the process/adoption/relation bytes are carried only through route-bounded cache material?
- How should recipient Role material be carried/resolved without making that Role a semantic participant or proving holder identity?
- What exact authority chain is sufficient for a fresh Role to distinguish established, unresolved and prohibited participant/process/source claims when no full repository is available?
- What must remain unresolved when only the cache contains nearby but unselected Roles/processes/material?
- What minimum qualified closure should Tooling expose to a fresh recipient as a grounding receipt without generating a plan or inventing semantics?

## Done Criteria

- Produce a qualified semantic disposition using existing Tiinex primitives wherever sufficient.
- State exact forward declaration/resolution rules for process applicability and requiredness in blank/minimal Workspace + cache delivery.
- State exact Role/cache interpretation boundaries for recipient Role, participant relevance, holder identity and capability relevance.
- Define the semantic acceptance contract Loom can implement mechanically without heuristically classifying prose or repository inventory.
- Identify any truly missing semantic primitive separately from Tooling/projection ergonomics; do not create one by convenience.
- Return a qualified Axiom-to-Anchor Handoff suitable for reconciliation under the controlling Business grounding Epic.

## Scope

Docs semantics only. No Core implementation and no Business mutation.

## Dependencies

- controlling Business Task: Blank-Workspace Role-Cache Grounded Progression Hardening;
- accepted Process Applicability And Cold-Grounding Semantic Disposition;
- accepted holder/source authority semantic disposition;
- current Role/Handoff/Relation/Workspace semantics.

## Boundaries

- Cache/material presence is not applicability, participation, holder identity, delegation or source authority.
- No reverse inventory or reverse-relation discovery.
- No requirement that every Role/process be carried for sparse work.
- No Business mutation.
