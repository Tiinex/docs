# OLLE Object Branch

This topic narrows the DIY branch into a line for printed trace lineages that
become physical objects through folding, cutting, or display.

## Current Read

The point is not generic papercraft alone.

The point is that a `.trace.md` lineage can be printed, handled, folded, and
shared as a tangible object while still carrying the same provenance idea in a
more playful medium.

## Design Direction

For this branch, continuation should usually prefer:

- physical transformation over abstract naming alone
- forms that still let a human recognize the lineage after folding
- playful desk-scale artifacts over heavy fabrication
- keeping the meme readable without losing the provenance signal

## Human-In-The-Loop Read

Good child topics under this branch should usually help later readers answer:

- what a printed lineage becomes when it is turned into a paper boat, hat, or plane
- whether the folded object preserves enough provenance cues to stay recognizable
- what photo or note would be needed if the physical form should later re-enter the trace chain
- whether the object is meant as a joke, a desk prop, an archive token, or a conversation starter

## Current Child Candidates

- folded trace boats
- folded trace hats
- folded trace planes
- desk-side lineage props
- photographed paper lineage artifacts

## Next Artifacts

- continue a shape-specific child when one fold pattern becomes the preferred meme
- attach photo evidence or workshop notes if the physical object should itself become lineage material
- keep the naming playful but the provenance legible
