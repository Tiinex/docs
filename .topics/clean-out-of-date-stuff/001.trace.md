# Topic Root

This artifact starts a local topic lineage.

The purpose of a topic root is to establish a recognizable local start
format that can hold continuity for a narrower working surface without
forcing the work itself to begin immediately.

For this topic, the working surface is the
`clean-out-of-date-stuff` folder.

This root should therefore be read as:

- local to the `docs` repository
- scoped to review and revision planning for material that may no longer
  belong in `docs`
- intentionally prior to any actual cleanup or deletion work
- allowed to add policy, process, or references later if the topic
  needs them

Recognizable topic-root pattern:

- one continuity start point
- one short statement of local purpose or scope
- optional local runtime surfaces such as policy or process
- support material treated as references rather than as primary lineage
  carriers

This root does not perform the cleanup. It only establishes a stable
place from which that review can later proceed.

Likely next local children from this root would be review-shaped or
triage-shaped continuations rather than action logs.
