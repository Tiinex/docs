# Memes Root

This topic opens the meme-planning line under the broader educational tree.

## Current Read

The current need is to preserve a clean hierarchy before concrete generation or revision tasks are added.

That means this root should hold the broad organizing rules that all meme subtopics share, while narrower branches carry only the constraints specific to their own axis.

## Shared Structure Rules

- keep one major organizing axis per level
- let earlier parents carry the common meaning so child topics stay smaller
- prefer concrete receiver, destination, or reference names at the leaves
- avoid duplicating format or publication rules when a parent already governs them

## Shared Format Default

- default aspect ratio: `1:1`
- default canvas size: `2048x2048`
- default output intent: one still image or still-first meme surface
- default safe-area assumption: central composition with enough margin for later text placement or crop tolerance

## Shared Format Conduct

- do not silently switch aspect ratio because one draft happened to look better
- do not mix multiple default resolutions in sibling topics without an explicit reason
- if a narrower topic overrides the root default, it should state the new ratio, the new target resolution, and why the root default is not sufficient there
- if a folder only changes visual format, prefer trace-local metadata or override text instead of another directory unless the format itself becomes a stable organizing axis

## Shared Branch Model

Useful branch families here include:

- domestic context in `home`
- workplace role context in `office`
- work-state or workflow context in `work`
- educational-stage context in `school`
- distribution destination in `socials`
- pop-culture source anchors in `pop-culture`
- reusable scenario DNA in `storyboards`

## Design Direction

- keep this root responsible for taxonomy, format defaults, and shared branch conduct
- let child topics carry only the narrower meaning they uniquely own
- use topic lineage first and defer task artifacts until the structure itself is stable enough to survive revision
