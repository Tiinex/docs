# Educational Root

This topic opens a broader educational line in the `docs` repository.

The purpose of this root is not to decide one output medium too early.

The purpose of this root is to give teaching-oriented material a continuity home
before it narrows into slides, visual explainers, image briefs, or other more
specific branches.

## Current Read

The current need is to keep educational intent broader than any one visual
format.

That means this root should be able to hold or spawn narrower lines such as:

- slide-oriented visual material
- explainer imagery
- prompt or handoff packets for cloud generation
- later educational evidence, critique, or decisions

## Design Direction

For this topic space, current structure should prefer:

- keeping the educational line broad enough to outlive one delivery format
- treating `slides` as one child branch rather than as the whole educational
  surface
- attaching future sibling branches when other educational forms appear
- keeping concrete generation asks in child tasks rather than in the root

## Next Artifacts

- continue a slides-focused child topic from this root
- continue visual-explainer, diagram, storyboard, prompt-pack, and review
  branches when those narrower lines need their own continuity home
- add later educational branches when another medium or teaching format needs
  its own narrower continuity line

## Current Branch Candidates

The current educational root should be broad enough to spawn several narrower
branches without treating any one of them as the whole educational surface.

Current good candidates include:

- `slides`
- `visual-explainers`
- `image-briefs`
- `storyboards`
- `diagrams`
- `prompt-packs`
- `review-and-critique`
- `lesson-sequences`
- `social-cards`
