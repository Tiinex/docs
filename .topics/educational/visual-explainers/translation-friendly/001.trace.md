# Translation-Friendly Visual Explainers

This topic is for visual explainers where the image must carry more of the
teaching load because text may need translation or reduced dependence.

## Design Direction

- keep the visual logic strong enough to survive language shifts
- avoid overloading meaning into dense caption text alone
- prefer visuals that teach even when wording changes later
