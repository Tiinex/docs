# Educational Slides Root

This topic opens a bounded line for educational slide material in the `docs`
repository.

The immediate goal is not to generate every image locally.

The immediate goal is to give future slide work a readable continuity home so
committed repo context, visual intent, task scope, and later generated assets
can be connected through lineage.

## Current Read

The current need is a handoff-friendly structure for visual material that may
be generated in Cloud ChatGPT after the repository is committed.

That means the local artifacts should help a later reader or cloud model see:

- what the slide material is for
- what concept or lineage the image should support
- what part of the repo currently grounds the request
- what still needs human review after image generation

## Design Direction

For this topic space, current structure should prefer:

- keeping the high-level visual direction in a topic root
- using child tasks for concrete generation asks or handoff packets
- attaching later evidence children when generated images or prompt packs are
  worth preserving as reusable support material
- attaching decisions separately if one visual direction becomes the governing
  default for a recurring slide family
