# Handoffs and Recovery

A downloadable file preserves content. A qualified **Workspace carrier** can preserve the exact project material and its recoverable boundaries. A **Handoff** communicates that a bounded responsibility is being transferred to a recipient. These are different things.

## Pick by intention

- “I need a copy of my game board.” An ordinary export may suffice.
- “I want to come back next week without reconstructing this conversation.” Preserve a verified Workspace checkpoint with the work needed for the next session.
- “Please give this task to another teammate or assistant.” First qualify the work and recipient transfer, then manufacture the appropriate Handoff Package V1 with an exact route and carried closure.

Tiinex tooling already supports making and inspecting packages. Use its selected mode and its actual projected recipient instructions. Don't hand-assemble a misleading lookalike ZIP or turn a pointerless carrier into a Handoff by adding prose.

## What a new reader should verify

Read the declared Start, qualify bootstrap/payload and carried Workspaces, select only the real Entry/Handoff route, and inspect current work and governing sources. A valid archive does not automatically establish acceptance, Task closure, publication or remote write rights.

## Save the useful things together

Carry the actual output files, editable sources and the qualified records that explain what they mean. Avoid detached patches and status notes that someone else must mentally combine. If the host cannot preserve or attach the full checkpoint, say so and keep the transfer degraded rather than claiming recoverability.

## Publication and Status are not the same

An artifact's declared `Status` and an independently verified published commit describe separate facts. Publication must be established from exact source evidence; it should not silently rewrite published artifact bytes or imply approval.

See [Preserve and continue](../getting-started/001-4-preserve-and-continue.trace.md) for the short first-use version.
