# Linux / Git

This topic keeps Linux/Git as the human-operated continuation surface for source recovery, transcript capture, and outbound drafting.

## Current Read

The key behavior here is not generic Linux usage.

The key behavior is using Linux/Git as the place where a shared ChatGPT page can be recovered, read, and turned into a durable trace without losing the provenance of where it came from.

That surface also carries the short email draft that was produced from the recovered conversation.

## Design Direction

Good continuation in this line should usually prefer:

- keeping the share-link recovery reproducible
- separating transcript extraction from drafted output
- preserving the link between source page, recovered text, and outbound mail
- using the git child for the recovered ChatGPT conversation and its follow-up artifacts

## Good Child Candidates

- shared ChatGPT transcript evidence
- outbound mail draft
- recovery notes for platform shares

## Next Artifacts

- continue the `git` child when a share page needs extraction
- preserve the drafted mail alongside the recovered transcript
- keep the Linux root light and routing-oriented
