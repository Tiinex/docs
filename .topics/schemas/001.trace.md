## Evidence Material

- The core proposed semantic is that an event should preserve only that something happened, not what someone thought, decided, or wanted.
- The copied response suggests a very small event shape centered on what happened, event time, event scope, event status, and optional event references.
- The copied response explicitly argues that evidence, feedback, decisions, and reductions should be able to attach later instead of being fused into the event itself.
